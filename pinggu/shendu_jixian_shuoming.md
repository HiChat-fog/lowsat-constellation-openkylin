# 深度学习基线说明（LSTM 预测式异常检测）

产出：`pinggu/shendu_jixian.py` → `pinggu/shendu_jixian_jieguo.json`
复跑：`python3 pinggu/shendu_jixian.py`（一条命令，固定随机种子 0，已验证结果逐位复现；仅训练用时字段随机器波动）

## 一句话结论

在与本评估现有基线完全相同的数据、标签与点调整 F1 协议下，一个 CPU 单线程的小型 LSTM
预测基线（torch 2.14.0+cpu）取得 **总 F1 = 0.817（召回 0.990、精确 0.696）**，
高于现有滑窗 z 分数基线（0.395）与全局 3σ 基线（0.414）——但见下文协议差异，
该数字不能与 Telemanom 论文的 0.94 直接排名。

## 协议（与 pinggu/smap_duibi.py 完全对齐）

- 数据加载：复用 `smap_duibi.jia_zai`（`np.load` 单通道 `.npy`）。
- 标签构造：复用 `smap_duibi.du_biao_qian`（`labeled_anomalies.csv` 的
  `anomaly_sequences` `[start, end]` 闭区间 → 点级标签）。
- 评价指标：复用 `smap_duibi.dian_tiao_zheng`（point-adjust 点调整 F1，
  含精确/召回/段检出）。通道顺序同为 T-1、P-1、C-1、E-1，总 F1 按 tp/fp/fn 累加。
- 报警表示：LSTM 逐点打点级报警（布尔数组），直接送入同一 `dian_tiao_zheng`；
  前窗长 64 个点无法预测、不报警（各通道异常段均起始于 550 之后，不受影响）。

## 方法与训练参数（Telemanom 的轻量 CPU 复现）

按通道独立：LSTM（1 层，隐藏 64，输入/输出 = 该通道维数）用滑动窗（窗长 64，
与任务指定口径一致）预测下一时刻向量；预测误差取各维绝对误差均值，滑动均值
（窗 10）平滑；阈值 = mu + k·sigma，k = 3.0 全通道统一、不调参。

| 参数 | 值 |
|---|---|
| 框架 | torch 2.14.0+cpu（venv `pinggu/.shendu_venv`，单线程） |
| 随机种子 | 0（torch / numpy / 批次洗牌生成器均固定） |
| 训练窗 | 前 min(1000, n/3) 个点（T-1/P-1/E-1 为 1000，C-1 为 754） |
| 窗长 / 平滑窗 | 64 / 10 |
| epoch / batch / lr | 30 / 32 / 1e-3（Adam，MSE） |
| 总训练用时 | 约 17 s（4 通道合计，远低于 20 分钟限制） |

## 防泄漏（如实记录）

- 训练只用每通道序列前 min(1000, n/3) 个点；其余全部点与既有基线同口径参与评估。
- 归一化（z 分数）统计只取训练窗内的非异常点。
- 任何与标注异常段相交的训练窗整窗剔除：T-1、P-1、E-1 的异常段均晚于训练窗
  （剔除 0 窗）；**C-1 训练窗 754 点中异常段 [550,750] 与之重叠，剔除 204/690 窗**。
- 阈值系数 k=3.0 对全部通道统一，未按标签调优。

## 一次性阈值校准（仅 T-1，任务明示允许）

T-1 用训练段误差估计阈值时 F1 = 0.000（0/2 段检出，阈值 0.353）：其标注异常段内
的预测误差（约 0.02–0.03）不高于正常段误差水平——LSTM 把这两段上下文/缓变异常
也预测得很好，任何由训练段统计出发的阈值都无法把它们分离出来。据任务允许的
"通道 T-1 上用最后 20% 无异常数据做阈值校准一次"，用 T-1 的 [6889, 8611] 段
（1723 个无异常点，校准窗不含标签异常；k 仍为 3.0 不变）重估 mu/sigma
（0.0212/0.0052，阈值 0.0369），T-1 升至 F1 = 0.908。校准只使用无异常数据估计
阈值，未对标签做任何搜索/调优；其余三通道均用训练段阈值，未做校准。
校准前后结果均写入 JSON（`tong_dao["T-1"]["xiao_zhun_qian"]`）。

## 与 Telemanom（Hundman et al., KDD 2018）的协议差异（诚实声明）

| | 本基线 | Telemanom 论文 |
|---|---|---|
| 训练/测试 | 无独立 train 集，只有 test 通道数据；用序列前 ≤1000 点训练（剔除标注异常） | 独立 train/test 分离，每通道完整训练集 |
| 模型 | CPU 单线程单层小 LSTM（隐藏 64，共约 17 s） | GPU 训练的较大 LSTM |
| 阈值 | 固定 mu+3σ（仅 T-1 一次校准） | 非参数动态阈值，且作者报告的为调优后结果 |
| 范围 | 4 个单通道（T-1/P-1/E-1 为 SMAP，C-1 为 MSL） | SMAP 55 通道 + MSL 27 通道全集 |

因此本结果（总 F1 0.817）与论文口径的 SMAP 0.94 / MSL 0.91 **量纲不同、不可直接排名**；
参照系数字仅作背景（沿用 `smap_duibi.py` 的 CAN_ZHAO 说明）。

## 结果

| 通道 | 点调整 F1 | 召回 | 精确 | 段检出 | 阈值来源 | 训练用时 |
|---|---|---|---|---|---|---|
| T-1 | 0.908 | 1.000 | 0.832 | 2/2 | T-1 末 20% 无异常段校准（一次，k 不变） | 5.3 s |
| P-1 | 0.750 | 1.000 | 0.600 | 3/3 | 训练段误差 | 4.3 s |
| C-1 | 0.818 | 1.000 | 0.692 | 2/2 | 训练段误差 | 2.6 s |
| E-1 | 0.692 | 0.939 | 0.548 | 1/2 | 训练段误差 | 4.4 s |
| **总** | **0.817** | **0.990** | **0.696** | — | — | ≈17 s |

对比既有方法（同协议同标签）：

| 方法 | 总点调整 F1 |
|---|---|
| 基线1 滑窗 z 分数 | 0.395 |
| 基线2 全局 3σ | 0.414 |
| **LSTM 预测（本基线）** | **0.817** |

E-1 只检出 2 段中的 1 段（漏检 [5000,5030]），召回 0.939 未达 1.0；精确率整体
不高（误报点较多），是本轻量基线的主要短板。结果如实报告，未做进一步调参。
